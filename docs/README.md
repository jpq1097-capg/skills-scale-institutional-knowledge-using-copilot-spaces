# OctoAcme Project Management Docs

This folder contains the core project management process guidance used by OctoAcme to plan, execute, communicate, and improve cross-functional work.

## Project overview

OctoAcme uses a simple, repeatable project management lifecycle to turn ideas into measurable outcomes. These documents provide a shared operating model for initiation, planning, execution, risk management, release, and continuous improvement so teams can align on goals, responsibilities, and success criteria.

## Process summary

- Initiate with a clear problem statement, stakeholder alignment, and success criteria.
- Plan scope, milestones, dependencies, risks, and ownership before work begins.
- Execute in short, measurable iterations with clear accountability and quality gates.
- Track progress, surface blockers early, and keep stakeholders informed through consistent communication.
- Release with verification, rollback readiness, and stakeholder communication.
- Review outcomes, capture lessons learned, and improve the process continuously.

## How to use this set

Use the project management overview as the entry point, then move to the process document that matches the stage of work you are in. Keep the relevant project artifacts in the repo and update them as the project evolves to keep decision-making grounded in current context.

## Related guidance

- Use the project charter or one-pager as the shared source of truth for goals, success metrics, and constraints.
- Keep status communication consistent with the team’s sync cadence and milestone reviews.
- Treat retrospectives and action tracking as core delivery activities, not afterthoughts.
