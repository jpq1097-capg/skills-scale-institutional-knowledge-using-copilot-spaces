# OctoAcme Project Management Docs

This folder contains the core project management process guidance used by OctoAcme to plan, execute, communicate, and improve cross-functional work.

## Purpose

These documents provide a shared operating model for managing project work from concept through delivery and retrospective. They are designed to help teams align on ownership, decision-making, quality expectations, and stakeholder communication.

## OctoAcme process summary

- Initiate with a clear problem statement, success metrics, and stakeholder alignment.
- Plan scope, milestones, dependencies, and risk ownership before work begins.
- Execute in measurable iterations with clear ownership, quality gates, and reporting rhythms.
- Track progress, escalate blockers, and keep stakeholders informed through consistent communication.
- Release with verification, rollback readiness, and stakeholder communication.
- Review outcomes, capture lessons learned, and close the loop with continuous improvement actions.

## Project lifecycle

1. Initiation — validate the need, define outcomes, and decide whether to proceed.
2. Planning — break work into deliverables, backlog items, milestones, and dependencies.
3. Execution & tracking — deliver iteratively, manage blockers, and monitor progress.
4. Risk & communication — surface risks early and keep stakeholders aligned.
5. Release & deployment — verify quality, deploy responsibly, and communicate impact.
6. Retrospective & improvement — capture learnings and turn them into action.

## How to use this set

Use the overview doc as a starting point, then jump to the process document that matches the stage of work you are in. Keep the project artifacts in the repo and update them as the project evolves.

## Related guidance

- Use the project charter / one-pager as the shared source of truth for goals and success metrics.
- Keep status communication consistent with the weekly sync and milestone review cadence.
- Treat retrospectives and action tracking as part of the delivery process, not as an afterthought.
